# Local RNL viewer adapter

Uses upstream Rich Netlist Viewer UI0.5.1 at commit a240fe6bd952a28d0b7497c5c394b6c04d1f6d9c, official runtime0.5.3. The vendor tree carries licenses and file hashes. Data remains in a same-origin iframe and WASM Worker. No public viewer/CDN receives private design data.

`mount(container,{sourceText,sourcePath,sourceHash?,sourceCommit?,scope?,mapping?,onSelect,onStatus})` returns `{update,select,setScope,destroy,dispose,frame}`. `sourceHash` is SHA256 of exact UTF8 text and checked if supplied. `mapping` is accepted for compatibility; the adapter computes its own bounded textual index and never trusts arbitrary server spans. Source lines are1-based inclusive. IDs encode source_path/scope/kind/name, not transient core object indices.

`onStatus` emits stale/loading/ready/unsupported/error, source_sha256, source_commit, coverage, limitations. On source change it invalidates immediately; selection callbacks only resume after the current RNL loaded acknowledgement. Failed parse keeps stale=true. `select({kind,name,scope})` selects a supported object via the upstream selection code, or returns false.

`onSelect` returns kind,id,name,scope,source_path,line_start,line_end,source_sha256,source_commit. A net also has every statement occurrence in `locations`. Mapping supports named Spectre instances using ordered parenthesized terminal lists and backslash continuations; it is not a complete Spectre language implementation.

Geometry coverage: all22subcircuits and the testbench in the current real-SAR source,711instances in total; the default is `PIPE_TOP_F4_RS9_N06`. `coverage.available_scopes` supports a scope selector and `setScope(name)` changes the displayed level. Internal hierarchy uses upstream navigation. External/behavioral/standard-cell masters appear as terminal-count boxes; MOS uses a4terminal symbol. `Switch` and `PIPE_OTA_Diff_Ideal` have specialized placements; other scopes use generic placement. Flat R/C/source decks also work. Dense connection lines can overlap and labels may be easier to select than symbol bodies.

Derived RNL is generated transiently from the bounded Spectre index. Electrical statements retain their terminals, models and parameters; display comments add placement/symbol records, and external includes are omitted from the transient display only. Unsupported/malformed statements fail visibly instead of silently disappearing. Display coordinates are derived positions, never native OA geometry. Text edits do not update the archived schematic or layout; those retain their original provenance.

Verified locally: official runtime places711/711instances across23levels with zero errors/warnings or unplaced objects (box-symbol hints retained). Real Chrome uses upstream hit testing: W0 click maps lines9–10; net12 wire click maps both occurrences; physical XSARA/XCORE label clicks and Enter drill down to the actual SAR, where physical I16 selection is mapped. Programmatic reverse selection is recorded separately. Changing parameters rebuilds a new hash; malformed source stays stale. Reports are in `validation/phase2/`; older isolated browser reports retain their provisional source-path labels and are not rewritten as integrated workbench evidence.

Deploy adjacent to vendor: `web/viewer-adapter/index.js` resolves `web/vendor/rnl-viewer/index.html`. Rebuild vendor with tools/viewer/build-viewer.mjs using the pinned upstream checkout and integrity-verified core archive. The additive ic-selection-bridge.js and one script tag are the only viewer interaction additions; no upstream selection/rendering implementation is replaced.
