# CMOS 反相器：从电路开始

这是一个独立的两管反相器，适合作为新用户建立仿真流程的起点。打开 **Library Manager → 基础电路 → CMOS 反相器 · 从电路开始 → 反相器原理图**，即可浏览元件、连线和全部器件参数；选择“仅电路网表”可以查看同一份源文件。

| 端口 | 含义 |
| --- | --- |
| `CLK` | 输入，连接两个栅极 |
| `CLKN` | 输出，连接两个漏极 |
| `VDD` | PMOS 源极和衬底连接 |
| `VSS` | NMOS 源极和衬底连接 |

M9 使用 `nch_ulvt_mac`，M10 使用 `pch_ulvt_mac`。两者的原始参数均为 `l=30n`、`w=250.0n`、`multi=1`、`nf=1`；所有其余面积、周长及器件参数也完整保留。这些参数描述电路本身，模型实现需要用户自行提供。

开始仿真前，请在新的环境配置流程中明确提供：

1. 自己可使用的仿真器和执行环境。
2. 能解析上述两个模型名的授权模型文件，以及由该模型文档确定的选择条件。
3. 电源值、输入激励、负载和分析条件。
4. 希望保存的信号及结果收集位置。

完成配置后应先核对生成的输入和依赖，再提交任务并查看返回结果。此单元尚未绑定运行项目，不携带服务器地址、模型路径、工艺选择、电源值、激励或分析配方；打开它不会启动仿真，也不会读取或套用既有用户的环境。

电气内容提取自仓库已公开的 `lib/pipetisar-real/RS9_L5_9bit_Bootstrap/schematic/RS9_L5_9bit_Bootstrap.scs` 中的 M9/M10。两条完整器件语句保持原始字节，原节点名保持不变，将内部节点 `CLKN` 暴露为输出，并封装为 `CMOS_INVERTER CLK CLKN VDD VSS`。原理图是新绘制的简洁布局，使用现有公开 EDA 符号和样式；它不声称复原原 Virtuoso 布局。

精确的公开来源、提取范围和绘图依赖哈希见 `docs/provenance.json`。该独立反相器尚未进行仿真，不引用原完整电路的性能结果。绘图依赖的说明见仓库 `lib/THIRD_PARTY_NOTICES.md`。
