# Public release scope

CircuitGit starts from application snapshot `58fa137a66724b2b7aa97e36ff8dfcc59e2a4c25` of the IC on GitHub development project. The new repository preserves its own initial commit and MIT license; private repository history is not imported.

Included: browser source and vendored dependencies, shared modules, CLI/MCP/plugin code, generic gateway/export/simulation tools, contracts, application tests and architecture documentation, a PDK-free RC source/configuration/bundle, and CircuitGit branding. A static adapter reuses the RNL viewer, Dockview layout and waveform renderer for GitHub Pages.

The later circuit-library release adds an explicit inventory of user-authored ADC exports under `lib/`: original native placement, wire and symbol records, dependency documentation, and before/after source hashes. These are read-only viewing snapshots until a complete reviewed simulator project is registered. The importer retains exported geometry and replaces one excluded PDK implementation with a clearly marked empty terminal interface. It does not claim electrical equivalence for that replacement.

Private server configuration, runtime chat/approval state, Cadence/PDK installations, model cards, third-party standard-cell implementations and unreviewed simulation archives remain in the original engineering repository. The release does not copy historical directories wholesale. `tools/dev/build_library.py` publishes only the files declared in the reviewed library catalog and checks paths, sizes, private machine paths and credential patterns.

Several retained tests and older notes describe the original PIPETISAR engineering integration. Those references are historical context, not included datasets or a claim that the public clone passed those private-data integrations. The public CI checks build/module contracts and self-contained reference tests; browser acceptance covers the static demo. Generic tools such as `tools/check_project.py` still require their original engineering inputs when invoked.

The demo's fixed RC geometry was authored for this public example. ADC library views instead use the recorded native exports. RC waveform values are mathematical reference data calculated in-browser, with current defined as entering R0 terminal 1. Opening the hosted workbench makes no local account requests, AI turns, Spectre jobs or Git mutations. The optional AI panel can explicitly connect to an operator-owned Codex node; see [remote-node setup](remote-node.md). That connection uses a real node project independently of the public library canvas and retains the existing reviewed circuit workflow.
