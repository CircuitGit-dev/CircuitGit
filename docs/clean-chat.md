# 简洁 AI 对话

Studio 主对话区只显示你的消息与 AI 自然语言回答，并支持基础 Markdown。工具结果、会话/回合 JSON、来源信息和持续上下文提示不再占据默认对话区。

- 需要查看技术记录时，从 `Window → AI执行详情` 打开独立窗口。
- 需要人工批准时，输入区出现“待批准”入口；打开后仍能查看具体操作与差异，再明确批准或拒绝。隐藏对话不会替你批准。
- 操作失败或连接中断时才显示简短错误入口，详细信息在执行详情中。上下文变化对旧批准请求的限制仍然生效。
- 输入框在180px默认高度与100px最小高度内保持可见。隐藏后重新打开保留已加载对话和未发送草稿。

这次仅更新三个前端文件。AI后端、命令行、模型调用和审批接口保持不变；旧dashboard默认的诊断模式也保留。

静态更新不会重启服务或刷新已打开的页面。正在进行的对话继续使用已加载的前端；在合适的时候自行刷新页面即可使用新界面。刷新前请保存需要保留的未发送草稿。

验证记录见 `validation/clean-chat-20261110/`：既有事件回放和明确标记的模拟交互用于前端验收，没有发起新模型回合，也未操作生产中的活跃对话。
