# 原生原理图波形查看器

当前 RNL Studio 使用 Plot 菜单进入探针模式，并在独立窗口显示这些相同的历史数据；普通选择不自动绘图。新操作流程见 [RNL Studio](rnl-studio.md#波形与探针)。下文保留首版数据、来源绑定和旧界面说明。

正式工作台已集成波形面板，使用真实 Spectre 导出数据。2026-11-10剩余电流与游标验收完成；当前安装入口见[使用说明](getting-started.md)。无需再应用旧交付包补丁。

## 操作

1. 打开 `http://127.0.0.1:8766/`，选择 `real-sar-20261106`、主图 `canonical: TB_PIPE_RS9_N06` 和已有 SAR 运行 `20261109T054442Z-1d9279ef0b-014b97a6`。
2. 点击 `VINP` / `ROP` 读取对应电压。查看电流时，小尺度下点击 **`VDD0` 名称标签**；或滚轮放大后点击 **器件本体**。全图缩小状态的器件中心可能同时命中 `VDD` / `0` 引脚。
3. 在面板显式选择 **`p` 端、into_terminal**，才读取 VDD0:p。选择器件本身不会猜测电流端口；无精确映射的节点会显示阻断原因。
4. 调整时间窗口和游标。显示曲线可以压缩点数，游标始终基于完整导出数据并标识插值方法。

名称点选、电流/游标、未知节点阻断及正常放大后的本体点选均有原工程的浏览器证据。首版验收摘要和截图保存在原工程的 `validation/first-release-20261110/`，未包含在此公开仓库中；见[发布范围](public-release.md)。放大补验验证器件选择及显式端口门控，电流数值由主验收和独立 CSV 重算验证；不将二者混写为一次测试。

## 配置与接口

网关从受信任本地配置读取 `waveform_bindings` 和 `waveform_derivatives`；HTTP请求不能指定任意路径或修改注册。换机器需恢复原运行记录、CSV/归档、独立电流目录和实际Git历史，再配置本地绝对路径并验证来源。克隆仓库不会自动复制现有runtime状态或生成此映射。

只读查询示例（仓库根目录）：

```bash
python3 -B tools/workbench/waveform_cli.py --gateway http://127.0.0.1:8766 signals 20261109T054442Z-1d9279ef0b-014b97a6
```

服务模块为 `tools/workbench/waveforms.py`，浏览器模块为 `web/waveforms/`，共用原图唯一选择上下文。三个专用GET接口提供信号目录、已核验映射和波形/游标值，具体字段见[接口契约](waveform-interface.md)。这些接口不会触发仿真或提取。普通任务状态回执 `run.json` 可随状态查询刷新；原始CSV、完整归档与源身份单独校验。
