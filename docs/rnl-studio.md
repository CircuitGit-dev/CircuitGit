`Project` / `Git` 菜单提供项目、canonical 源码和出处。canonical 修改经网关预览与明确保存；源码编辑器保留“提交后推送到已配置的私有 GitHub”选项，最终确认采用当时的勾选值。回执原样显示 commit 与 push_status，只有 confirmed 表示推送已确认。出错或结果不明时保留草稿，先核对版本与远端状态，不自动补推。Viewer 本地文本编辑/下载不代表已写入 Git。未保存 canonical 修改会立即停用不再匹配的图形/波形关联。动态标签、字体和部分引脚/图形细节仍标记为 `partial`，OA源文件与损失清单保留。

## 右侧仿真配置

`Simulation` 菜单或右上“仿真”显示右栏，可拖动分隔线调整宽度，也可隐藏。选择配置后，表单展示实际模板与当前配置编译所得参数、瞬态分析、求解器设置和保存信号。空白override继承模板，来源和完整指令可展开查看。

1. 修改表单或“完整配置 JSON”。二者往返保留字段；未知字段由编译器明确拒绝，不静默删除。
2. 点击“预览差异”，检查 JSON diff、实际保存清单与编译输入哈希。
3. 明确选择是否“提交后推送到已配置的私有 GitHub 仓库”（配置表单默认不勾选），再点击“保存配置”或“提交并推送配置”。回执保留实际 commit 和 push_status；只有 confirmed 表示推送已确认。
4. 点击“生成计划”。计划必须与当前保存配置的编译输入哈希一致。
5. 需要实际新仿真时，手动执行远端预检，再勾选确认并提交。更改配置或源码会使旧计划/预检失效。响应结果不明时保留原幂等键和回执，不自动重复提交。

本次验证只在独立副本完成配置提交和本地计划，没有运行新 Spectre、OCEAN、预检或模型回合。

**Spectre raw 保存**与 **OCEAN 导出**分开管理。raw 保存支持继承、追加，以及在已支持语法范围内替换显式清单；选择会改变派生仿真输入，不修改旧raw或原模板。OCEAN配置只决定从已保存数据导出哪些曲线。

电压保存必须对应实际观察到的net；电流要求实际instance及明确终端。当前只对两端独立电压/电流源提供已验证的p/n别名，其余使用实际连接位置。最多256个明确目标，不接受任意保存代码或通配符。replace要求至少一个电压，并确认OCEAN请求仍在保存范围；无法解析的旧保存语法会阻止替换。外部PDK内部行为及隐式默认保存量不在显式清单覆盖范围。

已有两套PIPE配置各有125个显式保存目标，包含VDD0:p，实际stop为24 ns、maxstep为2 ps。独立界面验收将maxstep改为4 ps并追加VDD，得到126项；preview、保存后descriptor和plan使用同一编译器，哈希一致。这是配置执行链路验收，不代表重新验收ADC性能。

未保存草稿按项目、配置和source commit分别保留在当前已挂载组件内。切换后回到同一身份可继续编辑；新提交不自动继承旧草稿。刷新整个页面会结束内存草稿，应先保存或复制。任务列表读取已有回执，选择已归档结果不会触发远端状态轮询；活动任务的远端观察使用明确按钮。

选中任务后，可通过 `Simulation → 收集选中任务的完整结果` 或任务卡收集已结束任务；完整raw收集确认后，通过 `Git → 归档选中任务至私有 GitHub` 发布到原有私有结果分支和Release。两者复用既有接口；返回accepted只表示请求已接受，最终完成由本地回执中的收集完整性、源/归档哈希和发布验证记录确认。可手动“查看 / 刷新本地回执”；没有新增远端轮询。已归档任务仅显示回执、资产和Release链接，不提供重复收集/归档按钮。

恢复的源码/配置推送和结果操作仅做明确标注的synthetic请求验证及已有真实回执读取，没有重新推送电路源码、重新收集/发布旧结果或运行仿真。

## Plot 菜单与独立窗口

先在顶部选择已有SAR运行 `20261109T054442Z-1d9279ef0b-014b97a6`。

- `Plot → 打开波形窗口`只打开独立同源窗口，不自动增加曲线。
- `Plot → 电压探针`进入电压探针，实体点击原图中的 `VINP` 或 `ROP` 加入真实历史曲线。
- `Plot → 电流探针`进入电流探针，点击 `VDD0` 名称，或放大后点击器件本体，再在独立窗口显式选择 `p` 端。
- `Esc` / 退出探针恢复普通选择；普通选中、下钻、打开窗口不会自动绘图。

菜单动作会同步打开窗口。浏览器拦截弹窗时显示提示，并仅保留与当前版本/运行/探针模式一致的待选信号；允许弹窗后可从菜单重新打开。关闭窗口后重新打开是新视图，不声称旧曲线自动恢复。两个主窗口的消息相互隔离；项目、运行或源码绑定变化会清除旧关联，迟到消息不能混入新数据。

首版精确图形绑定仍只有VINP、ROP和VDD0:p。125个保存信号名中6条曲线已可读取。未知节点不按同名猜测；研究库快照、未保存源码和失效映射不能添加不可信曲线。

VDD0:p使用158252个原生PSFXL采样点，0–24 ns、单位A、方向流入p。游标以完整数据为依据，非网格位置明确线性插值；显示压缩不改变测量依据。当前显示源与历史源的122字节尾注释差异仍由固定Git证明核验，没有放宽成任意忽略注释。更多来源说明见[波形文档](waveform-viewer.md)。

## 底部 AI

底栏复用既有AI客户端、服务和人工批准协议。`Window`菜单或右上AI按钮可显示/隐藏，分隔线可调整高度。默认180px与最小100px高度内输入框保持可见，消息、diff、错误和审批卡片在内部滚动。

隐藏不取消会话、不批准请求，草稿和已显示内容继续保留；待审批或暂停提示显示在宿主徽标。重新打开可继续查看。切换项目/源码后，旧上下文的批准按钮不会继续生效。本轮没有重复模型调用或安装全局插件；CLI/MCP入口见[AI说明](ai-workbench.md)。

```bash
python3 -B tools/workbench/launch.py --config config/workbench.local.json
```
