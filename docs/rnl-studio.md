# RNL Studio：原理图、仿真与波形工作台

当前网页入口是 RNL Viewer 上的 Studio。菜单打开可组合的原理图、仿真、波形、版本管理和 AI 面板；窗口可以关闭、拖动与重新组合。仓库首页 `/` 进入该工作台。早期独立 dashboard 已移除，其专用脚本和样式不再发布。

本机服务使用操作者配置的地址和端口；默认网关示例为 `http://127.0.0.1:8766/`。公共页面可先浏览已发布的电路库，连接本地 helper 后才取得该连接授权的编辑、AI 或远端执行能力。网页地址、AI 通路和仿真站点分别配置，不能从页面成功打开推断仿真已可运行。

## 电路与版本

在 **电路库** 选择 library、cell 和 view。Viewer 保留 RNL 的层级、符号、坐标、连线及缩放。当前编辑对象是 Git 中的电路源与所属 RNL 图形；读取和保存不需要 OA、PDK 或 Virtuoso。

**版本** 面板按当前 cell 展示文件、工作区差异、历史、提交/PR 和 Testbench CI。已配对的本地直接操作使用原文件 hash、检查点和持久回执。需要同时修改连接与位置/连线时，应统一保存电气源和所属 RNL 文件；只修改 Spectre 网表不会自动重画原理图。共享依赖和历史导入证据仍只读。详细约定见[电路库](circuit-libraries.md)和[Agent 电路库工具](library-agents.md)。

已保存的历史图可以独立浏览。将节点关联到仿真数据时，仍需核对精确的源、几何、终端和运行身份。界面应明确显示不匹配或未验证状态，不能用同名信号猜测映射。

## 仿真配置与远端执行

仿真面板集中显示选择的分析、参数、保存信号和已得到的数据；完整配置与回执可展开检查。可运行项目必须由操作者配置模型、远端环境和允许执行的 testbench。库中存在一个 cell 不等于已经注册仿真项目。

1. 修改配置并检查编译结果、实际参数与保存清单。
2. 保存电路/配置，生成绑定当前源与配置 hash 的计划。
3. 经当前站点允许的提交流程，将输入交给独立远端 Spectre 进程。
4. 查询原运行回执，收集日志、原始波形和后处理输出；归档操作保留原 run/source 身份。

源码或配置变化会使旧计划失效。结果不明时查询原回执，不创建另一个提交来掩盖未知结果。`accepted` 只表示接受请求；求解完成也不等于电路指标通过。现行执行流程见[独立仿真](simulation-migration-plan.md)。

Spectre 的 raw 保存清单决定仿真产生的数据；OCEAN/CSV 后处理决定从已保存结果导出哪些曲线，两者分别记录。添加电压或电流探针前，需要该运行实际保存了相应节点或明确器件终端。

## 波形与探针

在波形面板选择已有运行，再通过 **Plot** 菜单或波形列表添加曲线。电压探针对应网络，电流探针对应器件及明确终端。普通选中和层级下钻不应自动增加曲线。`Esc` 退出探针模式。

波形组件可停靠或作为独立窗口打开；浮动、放回布局与关闭由宿主管理。曲线显示随面板大小调整，显示降采样与完整数据测量依据分开。保存波形的读取不依赖当前原理图是否与历史完全一致；从原理图探测时仍严格检查映射。详见[波形查看器](waveform-viewer.md)与[可组合工作台](docking-workbench.md)。

## AI 与连接

底部 AI 可以显示或隐藏，并支持会话选择、模型选择及可展开的操作过程。隐藏窗口不会批准、取消或重播操作。网页聊天使用本地连接适配器；原生 Agent 可直接调用 MCP 工具，不必另开网页模型会话。参见[Agent 连接](agent-connections.md)。

项目、cell、文件 hash 和运行身份随上下文传递。权限失败、工作区变化或不完整写入会停止依赖操作。已配置的直接 library 操作与远端仿真授权分别处理。

## 开发与历史

本机使用已有配置启动：

```bash
python3 -B tools/workbench/launch.py --config config/workbench.local.json
```

启动器构建当前网页资源。修改后应检查源代码导入、生成资源及受影响组件；运行中的 AI 回合和审批回执需要在后端重启前保留。

2026-11-10 的首轮 Studio、私有 SAR 运行身份、原生图形覆盖及验收记录属于历史导入。完整当时说明保留在[固定 Git 版本](https://github.com/joshuazeng713/CircuitGit/blob/10e067bd341736d39cb1157562e76e9914a311e6/docs/rnl-studio.md)。其中的私有 runtime 路径、端口及运行号不是新克隆的默认配置。现有历史 provenance/hash 保持原样。
