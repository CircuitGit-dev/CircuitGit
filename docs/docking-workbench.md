# 可排列的 IC 工作台

在 Codex 中说“打开 IC 工作台”，由 `ic_workbench_open` 打开一个组合页面。原理图、历史波形和仿真配置沿用原有功能。配置与历史运行需要明确选择，不自动使用最近一次运行。

- 拖动标签到另一面板中央：合并为标签组；拖到边缘：形成上下或左右分屏。
- 拖动分隔线调整大小；聚焦分隔线后也可用方向键调整，Home 恢复对半。
- 双击标签或点击方框：最大化／还原。
- 点击 × 关闭当前标签；通过“视图”菜单恢复。全部关闭时显示恢复入口。
- “重置布局”恢复默认排列：上方原理图与仿真，下方全宽波形。

布局保存到本地工作区状态。关闭面板前保存该视图的快照：波形选择、时间范围与游标，原理图层级与视口，以及仿真编辑文本。尚未写完的 JSON 也保留为文本，不据此改动电路或提交仿真。保存失败时面板保持打开，界面说明原因。

切换标签和调整尺寸不会销毁组件。隐藏面板暂停跟随选择等刷新；关闭后释放渲染、监听和计时器。运行和审批具有独立生命周期，关闭窗口不会取消仿真或批准请求。

第一版支持最多 16 个已登记面板，包括已关闭但可恢复的面板；同一工作台只创建一个原理图实例。不同运行的波形和不同配置可以并排或放入标签组。布局仅发生在插件页面内部，不改变 Codex 外层标签页或系统窗口排列。

返回已有工作台时使用原 `workspace_id` 和 `workbench_id`（即工作台 descriptor 的 `view_id`），不要新建空工作区。直接打开原有三个独立窗口仍受支持。

## 实现

`apps/codex/ui/workbench/` 管理布局树与组件生命周期。`host.js` 为每个子视图提供共享连接上的独立适配器，保留项目、视图、source/run 和版本校验。`ic_workbench_layout` 与 `ic_view_snapshot` 只保存 UI 状态，均使用 revision 冲突检测；源码与工程数据路径不变。RNL 几何仍来自已有导出文件。

窗口关闭恢复和独立页面由同一组件实现。组合入口新增第四份 MCP UI resource，原有三个资源保留。实际原生窗口显示与测试宿主渲染须分别报告。
